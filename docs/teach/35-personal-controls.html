Where does Mini get its state?

Electron reduces the host's summaries to the latest active top-level session. A dedicated IPC allowlist restricts the panel to status, stop, and open. A Playwright test opens the real window while the gateway's scripted provider is waiting and observes its abort signal and the saved terminal status.

How do instructions stay separate from learned facts?

USER.md remains the profile. INSTRUCTIONS.md contains standing user-authored instructions and is recorded in the session's request header. Extraction adds core facts to MEMORY.md. A text editor compares the content it loaded with the current host content before replacing it, so it can surface changes made by another client.

What can the pricing table tell us?

The usage panel selects one retained session and reuses the host's cost calculation. Forks and imports can contain copies of token usage, so the view reports each history separately. Priced rows contribute to the subtotal. Unpriced models have token counts and an unknown estimate.
