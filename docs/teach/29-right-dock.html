29 · A column for the work, not another app

Cursor's Agents Window keeps the chat in the middle and puts Changes, Browser, Terminal, and Files in one column on the right. You pick a pane; you do not get four windows. The useful part is that the list is the extension point.

flowchart LR S["DOCK_PANES"] --> R[switcher] R -->|Changes| C[diff review] R -->|Browser| B[live page] R -->|Terminal| T[bash scrollback] R -->|Files| F[workspace tree]

Why is the terminal not a real shell?

The agent already ran the commands, and the log is the record. Showing that scrollback answers "what did it run?" without a second process that could escape the approval policy. An interactive terminal later replaces only TerminalPane.

How do you add a fifth pane?

Append an id and an English label to DOCK_PANES, add the Chinese string, and one branch in DockBody. The switcher renders whatever is in the list. It never imports the pane.

Lessons

  • A side column that is a list of panes stays small. Four hardcoded layouts do not.
  • Files and the change viewer already had a path guard. The new list uses the same one.
