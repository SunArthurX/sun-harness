28 · What Manus and a personal assistant still had

Plans, a browser, a sandbox, and schedules were already here. Manus still felt different because a list of items did not share one context, and the result was a file you open. Hermes and OpenClaw still felt different because they know who you are in a few lines, they can be invoked as a skill, and they can find an old conversation without stuffing it into the prompt.

Fresh context, then one file

flowchart TD Q["wide_research: question + items"] --> A["subagent: Alpha only"] Q --> B["subagent: Beta only"] A --> F["research/question.md"] B --> F F --> P["parent synthesizes"]

Why not a hundred subagents?

Manus rents a cloud computer per item. This harness runs on the laptop that also holds your keys. Eight items, one after another, keeps each note in its own session and leaves a markdown file. The parent still writes the conclusion. Parallel fan-out on one shared model queue would also scramble a scripted test, which is a hint that the provider is a single conversation, not a cluster.

Why HTML slides?

The valuable part of Manus Slides is a deck you can present, with notes, not a dependency on PowerPoint or an image model. make_slides writes one HTML file (arrow keys) and one notes file. The Deliverables list is how you find them, next to screenshots, figures, and research notes.

A profile that cannot grow forever

OpenClaw and Hermes both refuse to let "memory" mean "the whole transcript." USER.md is capped at 1,375 characters and is its own prompt section. Daily notes take one line per summarized assistant session and stay on disk. session_search is how the agent looks up the rest, the same search the sidebar already used.

Why is a skill a slash command?

Hermes treats every installed skill as /name. Custom commands still win, so a project command is not replaced by a skill of the same name. The logged message contains the skill body. Otherwise the model would see /deploy and the log would not explain what that meant.

Lessons

  • Wide research is a context rule (one item, one session), not a promise of a data center.
  • A profile with a hard cap is more useful than a memory file that slowly becomes the prompt.
  • Deliverables are a list of paths. A sentence that names a file is not the same thing.
