07 · Context budgets

Context is the scarcest resource in a harness. This iteration makes two budgets explicit: how much of the prompt rules may take, and how much history a given model can hold before it must be summarized.

Why not one total budget?

With one budget, order decides who loses. A 60k-character project AGENTS.md (a generated API reference, say) would push out your personal global rules, the ones evolution writes for you. Separate budgets make each layer's guarantee independent. The test "a huge project AGENTS.md cannot evict the global rules" pins it.

Compaction limit per model

limit(model) = min(thresholdTokens, contextWindow(model) − buffer)
deepseek-chat: min(200 000, 128 000 − 25%) = 96 000 tokens
qwen-max:      min(200 000,  32 768 − 25%) = 24 576 tokens

Switching to a smaller model

sequenceDiagram participant U as User participant A as Agent participant Big as Old model (1M) participant Small as New model (3k) U->>A: switch model → small, send "q3" A->>A: history 3 000 tokens > limit(small) 2 250 A->>Big: summarize transcript (old model first) alt old model works Big-->>A: summary → context/compaction (model: big) else old model out of quota A->>Small: summarize trimmed transcript (≤ 3 × limit chars) Small-->>A: summary → context/compaction end A->>Small: summary + recent turns + q3

Why is compaction lazy, at the next request, instead of happening inside "switch model"?

Because a model switch is a log event, and the loop derives everything from the log. Doing the work in the next run() means it is durable and resumable. If the app quits between the switch and the next request, the compaction still happens, and still with the right model, because the model/switch event records from.

What about quota fallback, where the old model cannot run?

The summarizer list is [old, new]. The new model gets a transcript trimmed to about three characters per token of its own limit. A summary from fewer tokens is better than a request that is guaranteed to fail.

Make limits a function of the model, not a constant. When a model change makes the old shape invalid, transform the state with whichever party can still read it.
