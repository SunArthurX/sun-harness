Private website credentials

The broker returns references for listing, replacing, and deleting credentials. Its macOS adapter seals the password with a Keychain-backed key. The ciphertext binds the reference to its exact HTTPS origin.

What changes while the vault is decrypting?

The document can navigate, or the owner can replace or remove the entry. Check the grant and the stored revision again before dispatch. The isolated renderer checks the document marker before setting a single visible password input.

flowchart TD
  A[User opens a private site] --> B[User chooses Fill saved password]
  B --> C[Issue grant for the current document and revision]
  C --> D[Decrypt through the system vault]
  D --> E{Grant and vault revision still current}
  E -->|Yes| F[Check isolated document and origin]
  E -->|No| G[Report unavailable]
  F --> H[Fill the eligible field]
  H --> I[User submits the form]

What if the site echoes the password?

The test site copies the value into its visible content. The private partition is never attached to the agent browser, even after login. The authenticated cookie stays in that partition. Closing the window clears its browser session.

flowchart LR
  A[Trusted desktop controls] --> B[Main-process broker]
  B --> C[Private site partition]
  C --> D[Close and clear]
  E[Model and gateway] --> F[Regular browser profile]
