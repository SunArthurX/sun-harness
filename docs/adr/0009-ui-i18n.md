# 0009 — English keys, Simplified Chinese dictionary

## Context

The desktop and the gateway web UI share one React renderer. The product is used in English and in Simplified Chinese. Specs and `AGENTS.md` keep documentation in English, so UI copy still needs a single source of truth that agents can extend without a string-id catalogue.

## Decision

Gettext-style: the English UI sentence is the lookup key. Simplified Chinese lives in `locale-zh-CN.ts`. Missing keys fall back to English. A scanner plus a completeness test (`apps/desktop/test/i18n.test.ts`) make “both languages” a failing test, not a checklist.

## Alternatives

Message ids (`nav.sessions`) need a parallel English file and drift when copy changes. ICU / FormatJS is heavier than two languages. Translating the CLI would mix machine output with scripts that parse it.

## Consequences

New UI copy is an English string plus one dictionary line. Tests fail the change if either is missing. The CLI, docs, and model prompts stay English.
